## Office Network Design and Implementation Using Cisco Packet Tracer

## Project Overview
Designed and implemented a small office network using Cisco Packet Tracer to understand practical networking concepts and configurations.

## Network Components
- 1 Cisco 2911 Router
- 2 Cisco 2960 Switches
- 1 Server
- 6 Workstations (PCs)

## Technologies and Concepts
- IP Addressing and Static IP Configuration
- VLAN Configuration
- Switch and Router Configuration
- LAN Design and Implementation
- Network Topology Design
- Basic Network Connectivity Testing

## Project Implementation
1. Designed the small office network topology.
2. Configured IP addresses for all workstations and the server.
3. Created and configured VLANs on Cisco switches.
4. Configured network devices using Cisco CLI.
5. Tested network connectivity.

## Tools Used
- Cisco Packet Tracer

## Project Files
- `.pkt` – Cisco Packet Tracer project file.
- `Screenshots/` – Network topology and configuration screenshots.

## Learning Outcomes
Gained practical experience in network design, IP addressing, VLAN configuration, switch management and basic network troubleshooting.
